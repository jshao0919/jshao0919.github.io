Start with a public source

Read what the source calls an object, describe broad visible structures, and retain what remains unknown. The entries cover historical families, reported names, and uncertain regional associations; they are not a complete or current inventory.

Optional image search is available on each record when scripts and network access are available. Returned images are unreviewed archive results, not a verified aircraft-photo collection. Direct Commons search links remain available without the gallery.
